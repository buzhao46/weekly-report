01系统级原则

三条原则来自 PRD 的产品定位，是一切视觉决策的上位依据。

克制不做装饰性渐变、大插画、动效堆砌；信息密度优先，服务「5 分钟写完周报」。
一致任何新 UI 一律从 Token 取值，禁止裸色值 / 裸字号 / 裸圆角。
可达正文对比 ≥ 4.5:1（WCAG AA）；键盘可达；触控目标 ≥ 36px。

03字体

系统字体栈，禁止引入 Web Font（本地单体应用）。数字一律 tabular-nums。

--fs-title 20px · 页面标题页面级唯一大字，如「我的周报」
--fs-base 14px · 正文基准详情正文、列表行高 1.6–1.8
--fs-control 13.5px · 控件按钮、输入框、表格单元格
--fs-small 13px · 次级文字说明、副标题
--fs-meta 12px · 元信息徽标、计数器、日志时间
temp-pwd · 等宽临时口令展示 x7Kp2m
字重：400 正文 / 500 次强调 / 600 标题按钮 / 700 评分数字与品牌标

04间距 / 圆角 / 阴影 / 动效

间距 4px 基数；全站唯一动效时长 120ms；卡片唯一阴影 --shadow-sm。

05按钮

每屏主按钮 ≤ 1 个；危险操作必须二次确认；行内操作用 btn-sm。

spec：padding 7px 14px · 控件字号 13.5px · hover 加深底色 · disabled opacity .5

06表单

字段错误 = 下方红字 + 边框变红，禁止只用 toast 报字段错误。

错误态：边框 --color-danger + 字段下方 12.5px 红字提示
