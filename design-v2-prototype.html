  • ③ 多文本框写周报 上周总结 / 本周计划均默认 1 条，可「+ 添加一条」。
  • ④ 附件内嵌正文写周报 每条条目支持拖拽 / Ctrl+V / 添加附件，文件以芯片形式嵌入正文，不做富文本、无优先级/投入比字段。
  • ⑤ 上周计划带入写周报 新建时自动弹出带入横幅，可编辑或移除。
  • ⑥/⑦ 可见范围写周报 自动导入上周设置；可选「全员公开 / 按部门 + 按人员」。
  • ⑧ 评论删除权限详情 统一为「删除」，不区分软删除；仅作者本人可删除自己的评论，他人评论不显示删除按钮。
  • ⑨ 点赞与分享详情 / 列表 任何可查看的他人日志均可点赞、转发。
  • ⑩ 分享 / 转发分栏我可查看的 「分享给我的」与「转发给我的」两个独立页签。
  • ⑪ 部门单层成员管理 人员表带「部门」字段，不支持层级；支持 Excel 导入。
  • ⑫ AI 总结二期 预留 MCP / WorkBuddy 接入位，界面标灰预埋。
  • ⑬ 登录 / 注册全局 打开原型先见登录门：账号口令登录、注册（姓名 / 账号 / 部门 / 口令），或免登录直接体验。
  • ⑭ 角色与权限全局 管理员 / 普通成员两级角色：导航按角色渲染（成员管理、平台设置仅管理员可见），越权访问拦截提示；成员表可分配 / 收回管理员（不能改自己、至少保留一名）。
  • ⑮ 通知系统全局 顶栏新增通知铃铛：未读数徽标 + 下拉面板（评论 / 点赞 / 转发 / 系统通知四类，彩色类型徽标，未读朱砂底 + 红点），点击通知跳转对应页面并自动已读；支持「全部已读」；评论、转发、修改留痕、提交等操作均提示「对方将收到通知」形成闭环；面板底部提供「⚡ 模拟推送」用于评审演示实时到达。通知保留 90 天。
  • ⑯ 全局搜索与归档全局 / 列表 / 详情 顶栏新增全局搜索：按关键词 / 人名 / 周期实时检索可见范围内全部周报，结果按「我的周报 / 我可查看的」分组并高亮命中词，点击直达对应视图；提供快速检索词。「我的周报」支持平铺 / 按周期归档切换（按月分组，标注篇数）；周报详情新增「上一篇 / 下一篇」归档翻页，条目、评论与操作按钮随报告整体切换。
  • ⑰ 草稿自动暂存与离开拦截写周报 编辑器输入停顿约 1 秒即静默暂存草稿，周期旁状态芯片实时显示「编辑中 / 已暂存 HH:MM」；存在未暂存修改时切换页面或退出登录会弹出拦截层（留在本页 / 丢弃并离开），丢弃后内容回退到上次暂存版本；关闭浏览器窗口同样拦截（beforeunload）。
  • ⑱ 变更记录版本化详情 / 列表 每次修改自动生成版本，报告持有完整版本链（v1 初版 → v2 → v3 当前）。弹层顶部可选任意两版对比（下拉选择或点击时间线「起点 / 终点」，支持 ⇄ 交换），diff 由版本数据实时计算而非静态截图；版本历史时间线展示各版时间与内容摘要。「我的周报」与详情页均有入口（详情页 meta 显示「已修改 N 次 · 查看版本」），无版本历史的报告不显示该入口。
  • 细节全局 报告周期（日/周/月）由配置决定启用；列表支持按人员 + 日期范围过滤；提交后不可删除仅可修改。
